Setup & Environment

Installing a C compiler and running your first program — on any operating system.

What happens when you run a C program?

C is a compiled language. Unlike Python or JavaScript, C source code (.c files) cannot be interpreted directly. It must be transformed into a native binary by a compiler. The pipeline looks like this:

StageInputOutputTool
Pre-processinghello.chello.i (expanded source)cpp
Compilationhello.ihello.s (assembly)cc1
Assemblyhello.shello.o (object file)as
Linkinghello.o + librarieshello / hello.exeld

You never need to run these steps individually — the gcc (or clang / cl) command does all of them for you with a single invocation.

Choosing a compiler

💡
For this course we use GCC because it is free, cross-platform, and the most common choice in educational and open-source contexts. Every example compiles cleanly with gcc -std=c17 -Wall -Wextra.

⚙ Installation Instructions

Debian / Ubuntu / Pop!_OS

GCC is available in the default repositories:

bash
# Update package index
sudo apt update

# Install GCC, Make, and the build-essential meta-package
sudo apt install -y build-essential

# Verify installation
gcc --version
# Expected output: gcc (Ubuntu ...) 12.x.x ...

Fedora / RHEL / Rocky Linux

bash
sudo dnf install -y gcc make
gcc --version

Arch Linux / Manjaro

bash
sudo pacman -S --noconfirm gcc make
gcc --version
✅
If you prefer Clang, install it with sudo apt install clang and replace gcc with clang in all commands below. The flags are identical.

Option A — Xcode Command Line Tools (recommended, no IDE needed)

This installs Clang (which is aliased as gcc on macOS) along with the standard C library headers:

bash — Terminal
# Opens an installer dialog if not already installed
xcode-select --install

# Confirm
gcc --version
# Apple clang version 15.x.x (clang-1500.x.x.x)

Option B — Homebrew GCC (true GCC, not Clang)

First install Homebrew if you haven't, then:

bash — Terminal
# Install Homebrew (skip if already installed)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install GCC (installs as gcc-13 or similar)
brew install gcc

# Check the installed version name
brew list --formula | grep gcc
# Use the versioned binary, e.g.:
gcc-13 --version
💡
On macOS the command gcc is Apple Clang. For the course examples either works perfectly. If you installed true GCC via Homebrew, substitute gcc-13 (or whichever version) in place of gcc.

Option A — MSYS2 + MinGW-w64 (recommended)

MSYS2 provides a Linux-like environment with a current GCC toolchain:

  1. Download the MSYS2 installer from msys2.org and run it.
  2. Open the MSYS2 UCRT64 terminal (from the Start Menu) and run:
MSYS2 UCRT64 shell
# Update package database
pacman -Syu

# Install GCC toolchain
pacman -S --noconfirm mingw-w64-ucrt-x86_64-gcc

# Confirm
gcc --version

Add C:\msys64\ucrt64\bin to your Windows PATH environment variable so you can run gcc from any terminal.

Option B — VS Code + MinGW-w64 (step-by-step)

  1. Follow Microsoft's official guide: Using GCC with MinGW in the VS Code C/C++ extension docs.
  2. Install the C/C++ Extension Pack in VS Code.
  3. Configure .vscode/tasks.json to call gcc on save.

Option C — Visual Studio (MSVC)

Download Visual Studio Community (free). Select the Desktop development with C++ workload. Use cl.exe instead of gcc.

⚠️
Windows users: avoid installing old MinGW from mingw.org — it is unmaintained. Use MSYS2 / MinGW-w64 which ships GCC 13+ and is actively maintained.

▶️ Compiling & Running a C Program

The workflow is identical on all three operating systems, with minor differences in the output file name and how you run it.

Step 1 — Write the source file

Save the following as hello.c:

hello.c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}

Step 2 — Compile

Terminal
# Compile with recommended warning flags
gcc -std=c17 -Wall -Wextra -o hello hello.c

# Run
./hello
MSYS2 / MinGW-w64 terminal
# Compile — produces hello.exe
gcc -std=c17 -Wall -Wextra -o hello hello.c

# Run (MSYS2 shell)
./hello.exe

# Run (Windows CMD)
hello.exe
Developer Command Prompt for VS
rem Compile
cl hello.c

rem Run
hello.exe

🔎 Recommended Compiler Flags

FlagMeaning
-std=c17Use the C17 standard (ISO/IEC 9899:2018). Also try -std=c11.
-WallEnable all common warnings. Always use this.
-WextraEnable extra warnings beyond -Wall.
-WpedanticStrictly enforce the standard; warn about non-portable extensions.
-gInclude debug symbols (required for gdb / LLDB).
-O2Optimise for speed (use for production; omit while debugging).
-o <name>Specify the output binary name.
-fsanitize=addressEnable AddressSanitizer to catch memory errors at runtime.

A good all-purpose development command:

bash
gcc -std=c17 -Wall -Wextra -Wpedantic -g -fsanitize=address -o myprog myprog.c

Verifying your setup — checklist

  • Run gcc --version — you should see a version number, not "command not found".
  • Compile and run hello.c — output should be Hello, World!.
  • Compile with -Wall -Wextra — zero warnings on a clean file means the toolchain is healthy.
