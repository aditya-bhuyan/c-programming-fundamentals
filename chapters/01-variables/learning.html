1. What is a variable?

A variable is a named region of memory that holds a value of a particular type. Every byte of your computer's memory has a numeric address; the compiler maps each variable name to the address of the first byte of its storage, so you can write age instead of something like 0x7ffee3a4b8ac.

The type tells the compiler two things: how many bytes to reserve, and how to interpret the bits stored there (as a signed integer, a floating-point number, a character, and so on).

Declaration, assignment and initialisation

TermSyntaxMeaning
Declarationtype name;Reserves storage and tells the compiler the name and type. For a local variable the value is indeterminate (garbage) until you set it.
Assignmentname = value;Stores a value in an already-declared variable.
Initialisationtype name = value;Declaration and first value in one step. Always preferred.
var_basics.c
#include <stdio.h>

int main(void)
{
    int age;               /* declaration: value is indeterminate */
    age = 30;              /* assignment */
    int height = 180;      /* declaration + initialisation */
    int a = 1, b = 2;      /* several variables of the same type */

    /* &variable is the address-of operator; %p expects a void * */
    printf("age    = %d stored at %p\n", age,    (void *)&age);
    printf("height = %d stored at %p\n", height, (void *)&height);
    printf("a + b  = %d\n", a + b);
    return 0;
}
⚠️
Reading an uninitialised local variable is a bug: its value is whatever bytes happened to be in that memory. Global and static variables, by contrast, are zero-initialised automatically.

lvalues and rvalues (briefly)

An lvalue ("locator value") is an expression that refers to a memory location, so it can appear on the left of an assignment. An rvalue is a plain value that has no storage you can assign to. Variables are lvalues; literals and arithmetic results are rvalues.

lvalue.c
#include <stdio.h>

int main(void)
{
    int x = 5;
    x = x + 1;        /* left x is an lvalue (a location);
                         right x + 1 is an rvalue (a value) */

    int *p = &x;      /* you can take the address of an lvalue ...   */
    /* int *q = &5;      ... but not of an rvalue: compile error      */
    /* 5 = x;            error: a literal is not an lvalue            */
    /* (x + 1) = 3;      error: the result of + is not an lvalue      */

    printf("x = %d, *p = %d\n", x, *p);
    return 0;
}

2. Integer types

C provides five integer types of increasing width: char, short, int, long and long long. Each has a signed form (the default, except possibly for plain char) and an unsigned form that stores only non-negative values but reaches twice as high.

TypeTypical sizeRange (signed)Range (unsigned)
char / signed char / unsigned char1 byte-128 to 1270 to 255
short / unsigned short2 bytes-32,768 to 32,7670 to 65,535
int / unsigned int4 bytes-2,147,483,648 to 2,147,483,6470 to 4,294,967,295
long / unsigned long8 bytes (4 on Windows and 32-bit systems)-9.22×1018 to 9.22×1018 (64-bit)0 to 1.84×1019 (64-bit)
long long / unsigned long long8 bytes-9,223,372,036,854,775,808 to 9,223,372,036,854,775,8070 to 18,446,744,073,709,551,615

The sizes above are typical, not guaranteed. The standard only promises minimum ranges: short and int hold at least 16 bits, long at least 32 bits, and long long at least 64 bits. It also guarantees sizeof(char) == 1 and that each type is at least as wide as the one before it (char ≤ short ≤ int ≤ long ≤ long long).

💡
Plain char may be signed or unsigned depending on the platform (signed on x86 and Apple silicon, unsigned on many ARM Linux targets). Use signed char or unsigned char when the sign matters, and plain char only for text.

Exact limits: <limits.h>

Never hard-code a range. The header <limits.h> defines macros such as INT_MIN, INT_MAX, UINT_MAX, LONG_MAX, LLONG_MAX, CHAR_BIT and CHAR_MAX that are correct for the platform you compile on.

Format specifierType

int_limits.c
#include <stdio.h>
#include <limits.h>

int main(void)
{
    printf("INT_MIN   = %d\n",   INT_MIN);
    printf("INT_MAX   = %d\n",   INT_MAX);
    printf("UINT_MAX  = %u\n",   UINT_MAX);
    printf("LLONG_MAX = %lld\n", LLONG_MAX);
    return 0;
}

3. Floating-point types

Floating-point types store real numbers in a binary scientific-notation format (sign, exponent, mantissa), as defined by IEEE 754 on virtually every modern machine. They have a huge range but limited precision: only a certain number of significant decimal digits are reliable.

TypeSizeSignificant digitsHeader
float4 bytes (32-bit)about 6–7 (FLT_DIG = 6)<float.h>
double8 bytes (64-bit)about 15–16 (DBL_DIG = 15)<float.h>
long double8, 12 or 16 bytes (platform dependent)15 to 33 (LDBL_DIG)<float.h>

<float.h> provides FLT_MAX, DBL_MAX, LDBL_MAX (largest finite values), FLT_MIN, DBL_MIN (smallest normalised positive values — not the most negative!) and FLT_EPSILON, DBL_EPSILON (the gap between 1.0 and the next representable number).

Literals: 3.14 is a double; append f for float (3.14f) or L for long double (3.14L). In printf, %f prints a double (a float argument is automatically promoted to double), so %lf is equivalent; long double needs %Lf. Use %e for scientific notation.

float_limits.c
#include <stdio.h>
#include <float.h>

int main(void)
{
    printf("FLT_MAX = %e  (about %d digits)\n", FLT_MAX, FLT_DIG);
    printf("DBL_MAX = %e  (about %d digits)\n", DBL_MAX, DBL_DIG);

    float  f = 0.1f;
    double d = 0.1;
    printf("float  0.1 = %.20f\n", f);   /* shows representation error */
    printf("double 0.1 = %.20f\n", d);
    return 0;
}
⚠️
Most decimal fractions such as 0.1 have no exact binary representation. Never compare floating-point values with ==; compare the absolute difference against a small tolerance instead.

4. The sizeof operator

sizeof is an operator (not a function) that is normally evaluated at compile time. It yields the size, in bytes, of a type or of an expression's type.

  • sizeof(type) — parentheses are required for a type name: sizeof(int).
  • sizeof variable or sizeof expression — parentheses are optional: sizeof count. The operand is not evaluated.
  • The result has type size_t, an unsigned integer type defined in <stddef.h> (and <stdio.h>). Always print it with %zu; using %d or %lu is non-portable.
sizeof_demo.c
#include <stdio.h>

int main(void)
{
    int    count = 0;
    double ratio = 0.5;

    printf("sizeof(int)    = %zu\n", sizeof(int));     /* type: parentheses needed */
    printf("sizeof count   = %zu\n", sizeof count);    /* variable: optional       */
    printf("sizeof(ratio)  = %zu\n", sizeof(ratio));   /* parentheses also fine    */
    printf("sizeof(long)   = %zu\n", sizeof(long));    /* platform dependent       */
    printf("sizeof(void *) = %zu\n", sizeof(void *));  /* 8 on 64-bit, 4 on 32-bit */
    return 0;
}

When you need an exact width, include <stdint.h> and use int32_t, uint64_t and friends. Use sizeof instead of hard-coded byte counts whenever you compute sizes (for example when allocating memory).

5. Type qualifiers and storage classes

Type qualifiers

  • const — the object may not be modified through this name after initialisation. The compiler rejects attempted assignments. Use it for constants and for pointer parameters you only read from.
  • volatile — the value may change in ways the compiler cannot see (hardware registers, signal handlers, memory shared with other threads or devices). The compiler must not cache it in a register or optimise away reads and writes.

Storage classes

KeywordMeaning
autoDefault for local variables: automatic storage, created on block entry and destroyed on exit. Almost never written explicitly.
staticInside a function: the variable keeps its value between calls and lives for the whole program. At file scope: the name is private to that source file (internal linkage).
externDeclares a variable that is defined elsewhere (another file, or earlier in this one). Allocates no storage by itself.
registerA hint that the variable should be kept in a CPU register. Modern compilers largely ignore the hint, and you cannot take the address of a register variable.
qualifiers.c
#include <stdio.h>

int global_count = 7;                /* defined here */

static int next_id(void)
{
    static int id = 0;               /* initialised once, persists across calls */
    return ++id;
}

int main(void)
{
    const int limit = 100;           /* read-only */
    extern int global_count;         /* refers to the definition above */
    register int i;                  /* hint only; &i would be illegal */
    volatile int device_flag = 0;    /* compiler must always re-read it */

    for (i = 0; i < 3; i++) {
        printf("id = %d\n", next_id());
    }
    printf("limit = %d, global_count = %d, flag = %d\n",
           limit, global_count, device_flag);
    return 0;
}

6. Naming rules & conventions

Rules for identifiers

  • May contain letters (a–z, A–Z), digits and the underscore.
  • Must not start with a digit: 2fast is invalid, fast2 is valid.
  • Are case-sensitive: count, Count and COUNT are three different names.
  • Must not be a reserved keyword.
  • Avoid names beginning with an underscore followed by an uppercase letter, or with two underscores — these are reserved for the implementation.

Reserved keywords (C17)

auto break case char const continue default do double else enum extern float for goto if inline int long register restrict return short signed sizeof static struct switch typedef union unsigned void volatile while _Alignas _Alignof _Atomic _Bool _Complex _Generic _Imaginary _Noreturn _Static_assert _Thread_local

Conventions

  • snake_case for variables and functions: max_speed, total_count.
  • UPPER_CASE for macros and constants: #define BUFFER_SIZE 256.
  • Choose descriptive names. i and j are fine for loop counters; elsewhere prefer student_count over sc.
  • Declare a variable as close as possible to where it is first used, and initialise it there.
naming.c
#include <stdio.h>

#define MAX_STUDENTS 30                 /* macro: UPPER_CASE */

int main(void)
{
    int student_count = 24;             /* valid, snake_case        */
    int count2 = 2;                     /* valid: digit not first   */
    int _hidden = 1;                    /* valid, but avoid _Upper  */
    /* int 2count;    invalid: starts with a digit      */
    /* int my-var;    invalid: '-' is not allowed       */
    /* int float;     invalid: reserved keyword         */
    /* int Count, count;  valid but confusing: case matters */

    printf("%d of %d seats used (%d %d)\n",
           student_count, MAX_STUDENTS, count2, _hidden);
    return 0;
}

7. Implicit type conversion (promotion)

When operands of different types meet in an expression, C converts them automatically. Knowing the rules prevents many subtle bugs.

Integer promotion

Before any arithmetic, operands of type char, short (signed or unsigned) and _Bool are converted to int (or to unsigned int if int cannot hold all their values). That is why 'A' + 1 is an int with value 66, and why short * short is computed in int and does not overflow at 16 bits.

Usual arithmetic conversions

After promotion, if the two operands still differ, the "lower" type is converted to the "higher" one. Roughly:

If one operand is……the other is converted to
long doublelong double
doubledouble
floatfloat
unsigned, with rank ≥ the other operand'sthat unsigned type (a negative signed value wraps to a large positive one)
otherwisethe higher-ranked integer type (int, long, long long)

Truncation on assignment

Assigning a value to a variable of a different type converts it silently. Converting a floating-point value to an integer discards the fractional part (it truncates toward zero and does not round): int x = 3.9; stores 3 and int y = -3.9; stores -3. Converting to a narrower integer type that cannot hold the value wraps modulo 2N for unsigned types and is implementation-defined for signed types.

promotion.c
#include <stdio.h>

int main(void)
{
    int          x  = 3.9;       /* truncated to 3 (-Wconversion warns) */
    double       d  = 7 / 2;     /* integer division first: 3, then 3.0 */
    double       d2 = 7 / 2.0;   /* 2.0 is double, so 7 becomes 7.0: 3.5 */
    unsigned int u  = 5;
    char         c  = 'A';

    printf("x  = %d\n", x);
    printf("d  = %.1f, d2 = %.1f\n", d, d2);
    printf("c + 1 = %d (an int)\n", c + 1);
    printf("u - 10 = %u (unsigned wrap-around)\n", u - 10);
    return 0;
}
⚠️
Mixing signed and unsigned operands is a classic trap: -1 < 1u is false, because -1 is converted to UINT_MAX. Compile with -Wall -Wextra to catch it.

Summary

  • A variable is a named, typed region of memory; declare it as type name; and initialise it at the point of declaration.
  • Variables are lvalues (they have an address); literals and computed results are rvalues.
  • Integer types (char, short, int, long, long long) come in signed and unsigned forms; their sizes vary by platform, so use <limits.h> (INT_MAX, INT_MIN, …).
  • float, double and long double trade range and precision against size; limits live in <float.h> (FLT_MAX, DBL_MAX, …).
  • sizeof yields a size_t; print it with %zu. Parentheses are required for types, optional for variables.
  • const forbids modification and volatile forbids caching; static, extern, auto and register control lifetime and linkage.
  • Identifiers use letters, digits and underscores, cannot start with a digit, and cannot be keywords. Use snake_case for variables and UPPER_CASE for macros.
  • Narrower types are promoted to int; mixed types are converted to the "higher" type; assigning a double to an int truncates (int x = 3.9; gives 3).
