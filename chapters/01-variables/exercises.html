1 Type Size Table Easy

Write a program that prints a two-column table of every primitive type and its size in bytes, using sizeof and %zu. The types are char, short, int, long, long long, float, double and long double. Sample output (sizes depend on your platform):

Expected output (on a 64-bit Linux/macOS system)
Type                 Bytes
        -------------------- -----
        char                  1
        short                 2
        int                   4
        long                  8
        long long             8
        float                 4
        double                8
        long double           8

Line up the columns with field widths such as %-20s.

sizeof(int) is evaluated at compile time. To avoid repeating yourself you may use a macro such as #define ROW(T) printf("%-20s %2zu\n", #T, sizeof(T)) — the #T operator turns the argument into a string literal.
2 Temperature Converter Easy

Store a temperature in Celsius in a double variable and convert it to Fahrenheit using F = C * 9/5 + 32. Print both values with two decimal places. Use 36.6 as the Celsius value:

Expected output
Celsius    : 36.60
        Fahrenheit : 97.88

Be careful with the formula: in C, 9 / 5 is integer division.

9 / 5 evaluates to 1 because both operands are int. Write 9.0 / 5.0 (or C * 9.0 / 5.0) so the arithmetic is done in double. Use %.2f to print two decimals.
3 Limits Explorer Medium

Include <limits.h> and print a formatted table of the CHAR_* and INT_* constants: CHAR_BIT, CHAR_MIN, CHAR_MAX, INT_MIN, INT_MAX and UINT_MAX. Right-align the values in a column with a header row.

Expected output (shape)
Constant   |        Value
        -----------+-------------
        CHAR_BIT   |            8
        CHAR_MIN   |         -128
        CHAR_MAX   |          127
        INT_MIN    |  -2147483648
        INT_MAX    |   2147483647
        UINT_MAX   |   4294967295

Pay attention to the specifier for each constant: UINT_MAX is an unsigned int.

Use %12d for signed constants and %12u for UINT_MAX. A separator line made of dashes and a + gives a neat table. Your CHAR_MIN/CHAR_MAX values reveal whether plain char is signed on your platform.
4 Overflow Detector Medium

Write a program that adds 1 to INT_MAX and prints both the original and the resulting value. Add a comment explaining why this is undefined behaviour for signed integers. Then add a safe check that tests for overflow before performing the addition.

Your program must compile cleanly with gcc -std=c17 -Wall -Wextra. Observe what happens at different optimisation levels (-O0 versus -O2) — the result of undefined behaviour is allowed to change.

A constant expression like INT_MAX + 1 may be flagged by the compiler at compile time; store INT_MAX in a volatile int first so the addition happens at run time. The safe test is if (a > INT_MAX - 1) — it never itself overflows. Do not write if (a + 1 < a); that relies on the very overflow you are trying to detect.
5 Type Promotion Puzzle Hard

For each expression below, first predict the type and value on paper, then write a program that prints them to verify. Print sizeof of each result where useful to confirm its type. Declare these variables:

variables
int          i = 5;
        double       d = 2.5;
        char         c = 'A';
        unsigned int u = 5;
        short        s1 = 200, s2 = 300;
        float        f = 1.5f;

Cover at least: int + double, char + int, unsigned int - int (negative result), int / int stored in a double, short * short, float + double, and 1 / 2 * 3.0 versus 3.0 * 1 / 2. Explain in comments any result that surprised you.

Work out each type first. int + double is double; char + int is int; for 5u - 10 the int 10 is converted to unsigned int, so the subtraction wraps modulo 232 and must be printed with %u. 1 / 2 * 3.0 is evaluated left to right: 1 / 2 is integer division and gives 0.
