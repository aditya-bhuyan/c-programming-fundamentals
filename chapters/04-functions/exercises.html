1 Power Function Easy

Implement double power(double base, int exp) that returns base raised to the integer power exp. It must work for positive, zero, and negative exponents. Do not use pow() from <math.h>.

Write a main() that tests it with these calls (use %g in printf for compact output):

  • power(2.0, 10), power(2.0, -3), power(5.0, 0), power(-3.0, 3), power(10.0, -2), power(1.5, 2)
Expected output
2 ^ 10  = 1024
2 ^ -3  = 0.125
5 ^ 0   = 1
(-3) ^ 3 = -27
10 ^ -2 = 0.01
1.5 ^ 2 = 2.25
Recall that x-n = 1 / xn. Handle exp < 0 by computing the positive power and taking the reciprocal. For the positive case, multiply result by base in a loop exp times, starting from result = 1.0.
2 String Length Easy

Implement size_t my_strlen(const char *str) that returns the number of characters in a C string, not counting the terminating '\0'. You may not use <string.h>.

Strings are covered fully in Chapter 5. For now, all you need to know is that a string is a sequence of characters ending with a null character ('\0'), and that str[i] gives the i-th character. Test it with "Hello", "", "C programming", and "a b", printing the result with %zu.

Expected output
"Hello"         -> 5
""              -> 0
"C programming" -> 13
"a b"           -> 3
Start a counter at 0 and loop while (str[length] != '\0'), incrementing it each time. When the loop stops, the counter equals the length.
3 Recursive Sum of Digits Medium

Write a recursive function int sum_digits(int n) that returns the sum of the decimal digits of n. For example, sum_digits(12345) is 1+2+3+4+5 = 15. A negative number should be treated like its absolute value. No loops allowed.

Identify the base case and the recursive case before you write any code. Test with 12345, 0, 9, -987, and 1000.

Expected output
sum_digits(12345) = 15
sum_digits(0)     = 0
sum_digits(9)     = 9
sum_digits(-987)  = 24
sum_digits(1000)  = 1
n % 10 is the last digit and n / 10 is the number with its last digit removed. Base case: when n < 10 there is only one digit, so return n. Recursive case: (n % 10) + sum_digits(n / 10).
4 Function Pointer Calculator Medium

Build a small calculator whose operations are stored in an array of function pointers. Define four functions add, subtract, multiply, divide (each double f(double, double)) and store them in binary_op ops[], using a typedef for the function pointer type.

Since interactive input with scanf comes in a later chapter, process these pre-set requests in a loop, where each request is (operation index, left, right) and index 0..3 maps to + - * /:

  • (0, 12, 4), (1, 12, 4), (2, 12, 4), (3, 12, 4), (3, 5, 0), (7, 1, 1)

Print an error for an invalid index and for division by zero instead of calling the function. Do not use a switch or an if chain to pick the operation.

Expected output
12.00 + 4.00 = 16.00
12.00 - 4.00 = 8.00
12.00 * 4.00 = 48.00
12.00 / 4.00 = 3.00
[ERROR] 5.00 / 0.00: division by zero
[ERROR] Invalid operation index 7
Declare typedef double (*binary_op)(double, double);, then binary_op ops[] = { add, subtract, multiply, divide };. After checking that the index is in range, call ops[index](left, right).
5 Tower of Hanoi Hard

Solve the Tower of Hanoi puzzle recursively. There are three pegs, A, B, and C, and n disks of different sizes stacked on A with the smallest on top. Move all disks to C, moving one disk at a time and never placing a larger disk on a smaller one.

Write unsigned long hanoi(int n, char from, char to, char via) that prints every move and returns the total number of moves. Call it with n = 3 and print the total, together with the formula 2n - 1.

Expected output
Tower of Hanoi with 3 disks:
Move disk 1: A -> C
Move disk 2: A -> B
Move disk 1: C -> B
Move disk 3: A -> C
Move disk 1: B -> A
Move disk 2: B -> C
Move disk 1: A -> C
Total moves: 7 (formula 2^3 - 1 = 7)
To move n disks from from to to: (1) move n-1 disks from from to via; (2) print the move of disk n from from to to; (3) move the n-1 disks from via to to. Base case: n == 0 means nothing to do. Total moves = moves in step 1 + 1 + moves in step 3.
