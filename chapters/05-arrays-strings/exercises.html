1 Array Statistics Easy

Write a program that finds the minimum, maximum, sum, and average of a fixed integer array of 10 elements. Use the array: { 42, 7, 19, 85, 3, 56, 71, 28, 14, 63 }.

Expected output
Array   : 42, 7, 19, 85, 3, 56, 71, 28, 14, 63
Min     : 3
Max     : 85
Sum     : 388
Average : 38.80

Requirements:

  • Use a single for loop to compute all four values simultaneously.
  • Initialise min and max to the first element before entering the loop.
  • Print the average with 2 decimal places using %.2f.
Declare int min = arr[0], max = arr[0]; long sum = 0; before the loop. Inside the loop, update with: if (arr[i] < min) min = arr[i]; and similarly for max; add to sum each iteration. Compute average as (double)sum / n after the loop.
2 String Reverse Easy

Write a program that reverses a string in-place without using any library functions (no strrev, no strlen). Test with the strings "algorithm" and "racecar".

Expected output
Original : algorithm
Reversed : mhtirogla

Original : racecar
Reversed : racecar

Algorithm:

  • Find the end of the string by walking a pointer (or index) until you hit '\0' — do not use strlen.
  • Use two indices — left starting at 0, right at the last character — and swap while left < right.
Find the length manually: int len = 0; while (s[len] != '\0') len++;. Then set right = len - 1; and use a while (left < right) loop to swap characters using a temp variable.
3 Binary Search Medium

Implement the binary search algorithm as a function that searches a sorted integer array for a target value. Return the index if found, or -1 if not found.

Expected output
Sorted  : 2, 5, 8, 12, 16, 23, 38, 56, 72, 91
Search 23  -> found at index 5
Search 38  -> found at index 6
Search 99  -> not found (-1)
Search 2   -> found at index 0

Function signature: int binary_search(const int *arr, int n, int target);

  • Maintain int low = 0, high = n - 1;.
  • In each iteration, compute mid = low + (high - low) / 2 (avoids integer overflow vs (low+high)/2).
  • If arr[mid] == target, return mid; if arr[mid] < target, set low = mid + 1; otherwise high = mid - 1.
  • If the loop exits without a match, return -1.
The loop condition is while (low <= high). Using mid = low + (high - low) / 2 instead of (low + high) / 2 prevents overflow when both indices are large.
4 Word Count Medium

Write a function int word_count(const char *s) that counts the number of words in a string, where words are separated by one or more space characters (' '). Leading and trailing spaces should be handled correctly.

Expected output
"Hello World"          -> 2 words
"  spaces  everywhere  " -> 2 words
"oneword"              -> 1 word
""                     -> 0 words
"   "                  -> 0 words

Hints:

  • Track a boolean flag in_word (0 or 1). Iterate through each character.
  • When you see a non-space character and in_word == 0, increment the word count and set in_word = 1.
  • When you see a space, set in_word = 0.
for (int i = 0; s[i] != '\0'; i++) { if (s[i] != ' ' && !in_word) { count++; in_word = 1; } else if (s[i] == ' ') { in_word = 0; } }
5 Matrix Multiply Hard

Write a program that multiplies two 3×3 integer matrices A and B and stores the result in matrix C. Print all three matrices with aligned columns.

Input matrices
A:                   B:
  1  2  3              7  8  9
  4  5  6              2  3  4
  7  8  9              1  5  6
Expected output
Matrix A:
   1   2   3
   4   5   6
   7   8   9
Matrix B:
   7   8   9
   2   3   4
   1   5   6
A x B = C:
  14  29  31
  44  67  82
  74 105 133

Matrix multiplication formula for 3×3: C[i][j] = A[i][0]*B[0][j] + A[i][1]*B[1][j] + A[i][2]*B[2][j], generalised as C[i][j] += A[i][k] * B[k][j] for k = 0 to N-1.

Use three nested loops: outer on i (rows of A), middle on j (columns of B), inner on k. Zero-initialise C with int C[N][N] = { {0} }; before the loops. Use printf("%4d", C[i][j]); for aligned output.
