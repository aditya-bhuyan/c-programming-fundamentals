1 Arithmetic Calculator Easy

Declare two int variables (for example a = 17 and b = 5). Compute and print the sum, difference, product, integer quotient and remainder. Then also print the quotient as a real number with two decimals.

Expected output (for a = 17, b = 5)
a = 17, b = 5
a + b = 22
a - b = 12
a * b = 85
a / b = 3
a % b = 2
a / b (real) = 3.40
To print a literal percent sign inside printf use %%. For the real quotient, cast one operand: (double)a / b.
2 Bit Flags Easy

Use an unsigned char as a flag byte, starting at 0. Set bits 0, 2 and 4, then print the value (in binary and decimal). Then clear bit 2 and print again.

Expected output
After setting bits 0, 2, 4: 00010101 (21)
After clearing bit 2:       00010001 (17)
Set with flags |= (1u << n); clear with flags &= ~(1u << n). To print binary, loop bit from 7 down to 0 and output (flags >> bit) & 1.
3 Short-Circuit Demo Medium

Write two functions, first() returning 0 and second() returning 1, each printing a message when called. Use them in four expressions — first() && second(), second() && first(), first() || second(), second() || first() — printing the result of each. Before running, predict which messages will appear for each expression.

Remember: && skips its right side when the left is false; || skips its right side when the left is true. Store each result in an int and print it after the expression.
4 Swap Without Temp Medium

Swap two integers using only the XOR (^) operator — no temporary variable. Print the values before and after.

Expected output (a = 12, b = 25)
Before: a = 12, b = 25
After:  a = 25, b = 12
Three statements: a = a ^ b; then b = a ^ b; then a = a ^ b;. XOR-ing a value with the same number twice gives the original value back.
5 Precedence Puzzle Hard

With int a = 5, b = 3, c = 2;, predict the output of each expression on paper first (write down how the compiler groups it), then write a program that prints all five and verify your predictions.

puzzle.c
a + b * c            /* 1 */
a - b - c            /* 2 */
a > b && b > c || c > a   /* 3 */
a & b == c           /* 4 */
a << 1 + c           /* 5 */

Your compiler will probably warn about some of these lines — read the warnings: they tell you what grouping the compiler chose.

Use the precedence table in the Learning section. Remember that == binds tighter than &, and + binds tighter than <<. Then rewrite each with full parentheses to confirm.
