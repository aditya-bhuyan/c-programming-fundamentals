1 Student Record Easy

Define a Student struct with a name (character array), an age (int) and a gpa (double). Create an array of 3 students, then print them sorted by GPA from highest to lowest. Write a separate function sort_by_gpa(Student *s, size_t n) that sorts the array in place.

Expected output
Name     Age  GPA
Bob      22   3.90
Alice    20   3.45
Carol    21   3.12
Use struct assignment to swap or move whole elements: Student tmp = s[i]; copies every member at once. An insertion sort or bubble sort is enough for 3 elements.
2 Point Distance Easy

Define a Point struct with double x, y. Write double distance(Point a, Point b) that returns the Euclidean distance between two points, and test it on at least two pairs. Link with -lm if your compiler requires it for sqrt.

Expected output
Distance (0,0) to (3,4)       = 5.0000
Distance (-1.5,2) to (4.5,-2) = 7.2111
The distance is sqrt(dx*dx + dy*dy) where dx = b.x - a.x and dy = b.y - a.y. Include <math.h>.
3 Linked List Node Medium

Define a self-referential Node struct holding an int value and a struct Node *next. Build a 5-node list containing 10, 20, 30, 40, 50 in that order, print it, then free every node. (This is a preview of Chapter 9, so malloc and free are all you need.)

Expected output
10 -> 20 -> 30 -> 40 -> 50 -> NULL
List freed.
Insert at the front by looping from the largest value down to the smallest. To free: save head->next in a temporary before calling free(head).
4 Tagged Union Calculator Medium

Use a tagged union Result that holds either an int or a double. Write add(int, int), which returns an int result, and divide(int, int), which returns an int result when the division is exact and a double result otherwise. Write print_result that inspects the tag and prints with the correct format specifier.

Expected output
7 + 5    = 12 (int)
12 / 4   = 3 (int)
7 / 2    = 3.5000 (double)
10 / 3   = 3.3333 (double)
Use a % b == 0 to detect an exact division. Remember to cast before dividing for the double case: (double)a / b.
5 Binary File Record Hard

Define a Record struct (int id, char name[24], double balance). Write an array of 3 records to a binary file with fwrite, then read them back into a second, zeroed array with fread and print them. Check every fopen for failure. (This is a preview of Chapter 8.)

Expected output
Wrote 3 records (40 bytes each) to records.bin
Read  3 records back

id=1 name=Alice  balance=1250.75
id=2 name=Bob    balance=310.00
id=3 name=Carol  balance=9999.99
Open with modes "wb" and "rb". fwrite(arr, sizeof(Record), count, fp) returns the number of records written. Close the file between writing and reading.
