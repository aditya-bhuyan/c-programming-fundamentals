Exercise 2 — Personal Profile Card

ex2_solution.c
#include <stdio.h>

int main(void) {
    const char *name   = "Alice Johnson";
    int         age    = 28;
    double      height = 5.6;
    char        grade  = 'A';

    printf("===========================\n");
    printf("Name   : %s\n",    name);
    printf("Age    : %d\n",    age);
    printf("Height : %.1f ft\n", height);
    printf("Grade  : %c\n",    grade);
    printf("===========================\n");
    return 0;
}
💡
Notice const char *name — a pointer to a string literal. We cover pointers fully in Chapter 6. For now, know that %s expects a pointer to a null-terminated character array.

Exercise 4 — Inspection Pipeline

ex4.c
/*
 * Exercise 4 — Inspecting the C compilation pipeline
 *
 * Observations:
 * 1. gcc -E ex4.c
 *    Output: the #include  is replaced by hundreds of lines of
 *    function declarations from the system header. Our code appears at the bottom.
 *
 * 2. gcc -S -std=c17 ex4.c → ex4.s
 *    The string "Inspecting the pipeline\n" appears as a .string directive.
 *    The call to printf becomes a 'call printf' assembly instruction.
 *
 * 3. gcc -c -std=c17 ex4.c → ex4.o
 *    Binary object file. Not human-readable directly (use objdump -d ex4.o).
 *
 * 4. gcc -std=c17 -o ex4 ex4.c && ./ex4
 *    Produces the executable and runs it immediately.
 *
 * 5. echo $?
 *    Prints 0 — our return 0; became the process exit code.
 */
#include <stdio.h>

int main(void) {
    printf("Inspecting the pipeline\n");
    return 0;
}

Exercise 5 — Escape Sequence Table

ex5_solution.c
#include <stdio.h>

int main(void) {
    printf("Escape  Effect\n");
    printf("------  ------\n");

    /* \n — the newline itself is the effect */
    printf("\\n      (newline — the next line starts here)\n");

    /* \t — horizontal tab */
    printf("\\t      (tab)\tlike this\n");

    /* \\ — literal backslash */
    printf("\\\\      one backslash: \\\n");

    /* \" — literal double quote */
    printf("\\\"      a quote: \"\n");

    /* %% — literal percent sign in printf */
    printf("%%%%      a percent: %%\n");

    return 0;
}
💡
Key insight: to print the two-character sequence \n literally (not as a newline), you need \\n in the source — the first \\ becomes a single backslash, followed by the literal n.
