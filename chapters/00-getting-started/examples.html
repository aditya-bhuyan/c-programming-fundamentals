Example 1 — Hello, World!

The classic first program. Demonstrates #include, main, printf, and return.

01_hello.c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
▶
Compile: gcc -std=c17 -Wall -o 01_hello 01_hello.c  |  Run: ./01_hello  |  Output: Hello, World!

Example 2 — Multiple printf calls

Demonstrates that printf does not add a newline automatically — you must include \n.

02_multiline.c
#include <stdio.h>

int main(void) {
    printf("Line 1\n");
    printf("Line 2\n");
    printf("No newline at the end of this line");
    printf(" — continued on same line\n");
    return 0;
}
▶
Output:
Line 1
Line 2
No newline at the end of this line — continued on same line

Example 3 — Format specifiers

Using %d, %f, %c, and %s to print different types.

03_format.c
#include <stdio.h>

int main(void) {
    int    age    = 25;
    double height = 5.9;
    char   grade  = 'A';

    printf("Age    : %d\n",    age);
    printf("Height : %.1f ft\n", height);
    printf("Grade  : %c\n",    grade);
    printf("Name   : %s\n",    "Alice");
    return 0;
}
▶
Output:
Age : 25
Height : 5.9 ft
Grade : A
Name : Alice

Example 4 — Exit codes

Using EXIT_SUCCESS and EXIT_FAILURE from <stdlib.h> (preferred over bare integers).

04_exit.c
#include <stdio.h>
#include <stdlib.h>   /* EXIT_SUCCESS, EXIT_FAILURE */

int main(void) {
    printf("Program running...\n");

    /* Using the named constants is more readable than 0 / 1 */
    return EXIT_SUCCESS;  /* equivalent to return 0; */
}
▶
After running, check the exit code: echo $? → 0

Example 5 — Inspecting pre-processor output

Shows how to stop after pre-processing to see what the compiler actually works with.

bash
# Stop after pre-processing; output goes to stdout
gcc -E 01_hello.c | head -40

# Stop after compiling to assembly
gcc -S -std=c17 01_hello.c       # produces 01_hello.s
cat 01_hello.s

# Compile to object file only (no linking)
gcc -c -std=c17 01_hello.c       # produces 01_hello.o
