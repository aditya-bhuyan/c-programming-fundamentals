Try to solve each exercise yourself before looking at the solutions. Write your code in a text editor, compile with gcc -std=c17 -Wall -Wextra -o ex<N> ex<N>.c, and run it to verify your output.
1 Hello, Name! Easy

Write a C program that prints the following three lines to standard output:

Expected output
Hello, World!
Hello, C!
Hello, Programmer!

Each greeting must be on its own line. You must use three separate printf calls.

Each printf call should end its string with \n to move to the next line.
2 Personal Profile Card Easy

Write a C program that uses printf to display a profile card for yourself (or an imaginary person) in the following format:

Expected output (values are examples)
===========================
Name   : Alice Johnson
Age    : 28
Height : 5.6 ft
Grade  : A
===========================

Use appropriate format specifiers: %s for name, %d for age, %.1f for height, and %c for grade.

Declare variables for each field first, e.g. int age = 28;, then pass them as arguments to printf.
3 ASCII Art Box Easy

Print the following ASCII art box using only printf:

Expected output
+----------+
|  Hello   |
|  World   |
+----------+

Hint: the | character is typed with Shift+\.

Use one printf per line, each ending in \n. No special tricks needed — just careful spacing.
4 Inspection Pipeline Medium

Create a file called ex4.c with a simple printf program. Then run the following commands in your terminal and observe each output:

  1. Pre-process only: gcc -E ex4.c
  2. Compile to assembly: gcc -S -std=c17 ex4.c — open ex4.s and find your string.
  3. Compile to object file: gcc -c -std=c17 ex4.c
  4. Link and run: gcc -std=c17 -o ex4 ex4.c && ./ex4
  5. Check exit code: echo $?

Deliverable: Write a comment at the top of your ex4.c describing what you observed in each step.

In the .s file look for a .string or .ascii directive — that's your printf string in assembly form.
5 Escape Sequence Table Medium

Write a program that demonstrates every common escape sequence by printing a table like:

Expected output
Escape  Effect
------  ------
\n      (newline — the next line starts here)
\t      (tab)	like this
\\      one backslash: \
\"      a quote: "
%%      a percent: %

The \n row should visually show the newline by printing text before and after it on separate lines.

To print a literal backslash, use \\. To print a literal double-quote inside a string, use \". To print a percent sign with printf, use %%.
