Chapter 0 — Getting Started

History of C, the compilation model, your first program, and reading output.

Overview 📖 Learning 💻 Examples 🧠 Quiz 🏋 Exercises ✅ Solutions

What you will learn

  • The history and design philosophy of C
  • The compilation pipeline: preprocessing → compilation → assembly → linking
  • Writing, compiling, and running your first C program
  • Using printf to display text and values
  • Understanding the main function and return codes

Prerequisites

No prior programming experience is required for this chapter. You do need a working C compiler — see the Setup & Environment page.

Estimated time

Reading + examples: ~45 minutes. Quiz + exercises: ~30 minutes.
