Chapter 9 — Dynamic Memory Management

malloc, calloc, realloc, free, memory leaks, and Valgrind.

Overview 📖 Learning 💻 Examples 🧠 Quiz 🏋 Exercises ✅ Solutions

What you will learn

  • Allocate heap memory with malloc and calloc
  • Resize allocations with realloc
  • Always free memory to avoid leaks
  • Detect memory errors with Valgrind or AddressSanitizer
  • Understand common pitfalls like use-after-free and double-free

Prerequisites
