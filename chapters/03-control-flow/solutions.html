Exercise 1 — FizzBuzz

ex1_fizzbuzz.c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 100; i++) {
        if (i % 15 == 0) {
            printf("FizzBuzz\n");
        } else if (i % 3 == 0) {
            printf("Fizz\n");
        } else if (i % 5 == 0) {
            printf("Buzz\n");
        } else {
            printf("%d\n", i);
        }
    }
    return 0;
}
💡
Key Insight: The order of conditions in an if / else if chain matters. Since any multiple of 15 is also divisible by 3 and 5, testing i % 15 == 0 first guarantees that FizzBuzz is printed before the individual 3 or 5 branches can intercept it.

Exercise 2 — Number / Star Triangle

ex2_triangle.c
#include <stdio.h>

int main(void) {
    int height = 5;

    for (int row = 1; row <= height; row++) {
        for (int col = 1; col <= row; col++) {
            printf("*");
        }
        printf("\n");
    }
    return 0;
}
💡
Key Insight: The inner loop upper limit is row, causing row 1 to print 1 star, row 2 to print 2 stars, up to row 5 printing 5 stars. The newline printf("\n"); executes once per row after the inner loop finishes.

Exercise 3 — Prime Sieve (Sieve of Eratosthenes)

ex3_sieve.c
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    bool is_prime[101];

    /* 1. Initialize all entries as prime candidates (true) */
    for (int i = 0; i <= 100; i++) {
        is_prime[i] = true;
    }
    is_prime[0] = false;
    is_prime[1] = false;

    /* 2. Sieve multiples starting from p * p */
    for (int p = 2; p * p <= 100; p++) {
        if (is_prime[p]) {
            for (int multiple = p * p; multiple <= 100; multiple += p) {
                is_prime[multiple] = false;
            }
        }
    }

    /* 3. Output results */
    printf("Primes up to 100:\n");
    for (int i = 2; i <= 100; i++) {
        if (is_prime[i]) {
            printf("%d ", i);
        }
    }
    printf("\n");
    return 0;
}
💡
Key Insight: Starting the inner loop at p * p is an important mathematical optimization: all smaller multiples of p (e.g. 2*p, 3*p) have already been crossed out by earlier prime factors smaller than p.

Exercise 4 — Menu Simulator

ex4_menu.c
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int user_actions[] = { 1, 2, 4, 3, 9, 5 };
    int total_actions = sizeof(user_actions) / sizeof(user_actions[0]);

    printf("--- ATM System Initialized ---\n");

    bool running = true;
    int index = 0;

    while (running && index < total_actions) {
        int choice = user_actions[index++];
        printf("[Action] Choice %d -> ", choice);

        switch (choice) {
            case 1:
                printf("Action: Checking Balance ($1,250.00)\n");
                break;
            case 2:
                printf("Action: Deposit Funds ($200.00 deposited)\n");
                break;
            case 3:
                printf("Action: Withdraw Funds ($50.00 dispensed)\n");
                break;
            case 4:
                printf("Action: Account Statement Generated\n");
                break;
            case 5:
                printf("Action: Exiting system. Thank you!\n");
                running = false;
                break;
            default:
                printf("[ERROR] Invalid menu choice. Please select 1-5.\n");
                break;
        }
    }

    printf("Session ended successfully.\n");
    return 0;
}
💡
Key Insight: Setting a flag variable like running = false; inside case 5: is the standard structured programming approach in C to break out of the enclosing while loop from within a nested switch statement.

Exercise 5 — Palindrome Number Checker

ex5_palindrome.c
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int test_numbers[] = { 12321, 12345, 1001, 7, -44 };
    int count = sizeof(test_numbers) / sizeof(test_numbers[0]);

    printf("Checking numbers:\n");

    for (int i = 0; i < count; i++) {
        int original = test_numbers[i];

        if (original < 0) {
            printf("%5d -> NOT a palindrome (negative numbers cannot be palindromes)\n", original);
            continue;
        }

        int temp = original;
        long long reversed = 0;

        while (temp > 0) {
            int digit = temp % 10;
            reversed = reversed * 10 + digit;
            temp /= 10;
        }

        if (original == reversed) {
            printf("%5d -> PALINDROME (reversed: %lld)\n", original, reversed);
        } else {
            printf("%5d -> NOT a palindrome (reversed: %lld)\n", original, reversed);
        }
    }

    return 0;
}
💡
Key Insight: Using long long for reversed prevents integer overflow if reversing a large 32-bit integer causes digits to exceed INT_MAX before comparison.
