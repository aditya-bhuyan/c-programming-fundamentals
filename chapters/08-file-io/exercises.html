1 Line Counter Easy

Write a program that opens a specified text file (for example, create a sample test file sample.txt containing a few lines of text), counts the total number of lines in the file by counting newline characters ('\n'), and prints the count. Ensure you handle errors gracefully if the file cannot be opened.

Expected output
File: sample.txt
Total lines: 4
Use int ch; while ((ch = fgetc(fp)) != EOF) { if (ch == '\n') lines++; }. Don't forget to close the file with fclose(fp) when done.
2 File Copy (Character by Character) Easy

Write a program that copies the contents of a source file (source.txt) to a destination file (destination.txt) character by character using fgetc() and fputc(). Check for errors opening both files, count the total number of bytes copied, and report the result.

Expected output
Copied 52 bytes from 'source.txt' to 'destination.txt' successfully.
Open the source file with "r" and destination file with "w". If the second fopen fails, remember to close the first open file before exiting!
3 CSV Parser & Average GPA Calculator Medium

Write a program that creates a CSV file named grades.csv containing student records with columns Name,Major,GPA. Then reopen the file, parse each record line-by-line using fgets() and sscanf() (skipping the header row), print each student's details, and compute and print the class average GPA.

Expected output
Student Records:
- Emma Watson (Computer Science): GPA 3.90
- Liam Neeson (Mathematics): GPA 3.40
- Sophia Chen (Physics): GPA 3.80
- Noah Davis (Engineering): GPA 3.70

Total students: 4
Average GPA: 3.70
Use sscanf(line, "%31[^,],%31[^,],%lf", name, major, &gpa) to parse comma-separated fields into separate variables. Accumulate total GPA and record count in a loop.
4 Binary Record Database with Random Access Search Medium

Define a structure Product with fields int id, char name[32], and double price. Write a program that writes 5 products with IDs 101 through 105 to a binary file catalog.bin using fwrite(). Then, implement a function int find_product_by_index(FILE *fp, int index, Product *out) that uses fseek() to jump directly to the $k$-th record without reading previous records, loads it with fread(), and displays the found item.

Expected output
Database created with 5 products.
Looking up product at index 2 (offset 2 * sizeof(Product))...
Found: ID = 103, Name = Mechanical Keyboard, Price = $89.99

Looking up product at index 4 (offset 4 * sizeof(Product))...
Found: ID = 105, Name = USB-C Hub, Price = $29.50
Use fseek(fp, (long)index * sizeof(Product), SEEK_SET). If fseek succeeds, call fread(out, sizeof(Product), 1, fp) and verify that fread returns 1.
5 Log File Rotator Hard

Implement a function void log_message(const char *filename, const char *msg) that appends a timestamped message to a log file. Before appending, check the size of the log file using fseek(fp, 0L, SEEK_END) and ftell(fp). If the file size exceeds 1,024 bytes (1 KB), close the file, rotate it by renaming it to app.log.bak (overwriting any previous backup using remove() and rename()), and create a fresh new app.log file.

Expected output
Writing log entries...
Entry 1 written (size: 45 bytes)
...
Entry 22 written (size: 990 bytes)
Entry 23: Log size exceeded 1024 bytes (1035 bytes). Rotating 'app.log' -> 'app.log.bak'...
Rotation complete. Fresh 'app.log' created.
Entry 24 written to new active log (size: 45 bytes)
To check size without truncating, open with "a+" or "r". If size ≥ 1024, close the handle, call remove("app.log.bak"), call rename("app.log", "app.log.bak"), and open a new app.log with "w".
