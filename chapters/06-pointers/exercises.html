1 Pointer Basics & Indirect Modification Easy

Write a C program that declares an int variable with value 42, a double with value 3.14159, and a char with value 'Z'. Declare corresponding pointer variables for each. Print the value of each variable, its memory address via the pointer, and then modify each value exclusively using pointer dereferencing.

Expected output (addresses will vary)
Initial:
int val:    42 at address 0x7ffee40
double val: 3.141590 at address 0x7ffee38
char val:   Z at address 0x7ffee37

After modification via pointers:
int val:    100
double val: 2.718280
char val:   A

Ensure you cast pointers to (void *) when formatting with %p in printf.

Use int *p_i = &val; to store the address, *p_i to read or write the value, and (void *)p_i when printing with %p.
2 Array Sum via Pointer Arithmetic Medium

Write a function long long sum_array(const int *arr, size_t n) that computes and returns the sum of all elements in an integer array using pointer arithmetic only. You are not allowed to use square brackets ([]) inside the function body.

Expected output
Array: [10, 25, 30, 45, 50, 60]
Sum = 220

In main(), test your function on an array with at least 5 elements.

Create a pointer const int *end = arr + n; and loop while arr < end, accumulating *arr and incrementing with arr++.
3 Generic and Typed Pointer Swaps Medium

Write two functions: swap_int(int *a, int *b) and swap_double(double *a, double *b). Then write a generic byte-level swap function swap_generic(void *a, void *b, size_t size) that swaps the memory bytes between any two objects of the given size. Test all three functions in main().

Expected output
int swap:    a = 10, b = 20 -> a = 20, b = 10
double swap: x = 1.50, y = 9.75 -> x = 9.75, y = 1.50
generic:     p = 12345, q = 67890 -> p = 67890, q = 12345
For swap_generic, cast void * to unsigned char * and loop through size bytes, swapping one byte at a time using a temporary unsigned char.
4 Reverse Array In-Place (Two-Pointer Technique) Hard

Write a function void reverse_array(int *arr, size_t n) that reverses an array of integers in-place using the two-pointer technique. One pointer begins at the start of the array and another pointer begins at the last element. The pointers step toward each other, swapping elements, until they meet.

Expected output
Original: 1 2 3 4 5 6 7
Reversed: 7 6 5 4 3 2 1

No auxiliary array or indexing brackets ([]) should be used inside reverse_array.

Initialise int *left = arr; and int *right = arr + n - 1;. Loop while left < right, swap *left and *right, then do left++; right--;. Guard against n == 0!
5 Bounded String Copy Implementation Hard

Implement your own safe, bounded string copying function: char *my_strncpy(char *dst, const char *src, size_t n). The function must copy characters from src to dst using only pointer arithmetic and dereferencing. It must ensure the destination is always null-terminated (if n > 0) and prevent writing beyond n - 1 characters. The function should return dst.

Expected output
Source:      "C Programming Fundamentals"
Copied (30): "C Programming Fundamentals"
Copied (14): "C Programming" (truncated safely with null terminator)
Save the original dst in a pointer char *start = dst; to return at the end. Copy up to n - 1 non-null characters using *dst++ = *src++, then append *dst = '\0'.
