1. What is a pointer?

Every variable in a C program resides at a specific location in system memory (RAM). This location is identified by a numerical memory address. A pointer is simply a variable whose stored value is the memory address of another variable or object.

To declare a pointer variable, place an asterisk (*) before the variable name in the declaration:

pointer_decl.c
int  *p;     /* p is a pointer to an int */
char *cp;    /* cp is a pointer to a char */
double *dp;  /* dp is a pointer to a double */

To print a pointer address using printf, use the %p format specifier. The C standard requires casting the pointer to (void *) when passing it to printf with %p.

The NULL pointer

A pointer that does not point to any valid object or function should be set to NULL (defined in <stddef.h>, <stdio.h>, and <stdlib.h>). In C, NULL is an implementation-defined null pointer constant, typically ((void *)0) or 0.

null_ptr.c
#include <stdio.h>
#include <stddef.h>

int main(void) {
    int *p = NULL;  /* p points to nothing */
    printf("p = %p\n", (void *)p); /* prints (nil) or 0x0 */
    return 0;
}
💡
Always initialise pointers when you declare them. If a pointer does not yet have a target object, initialise it to NULL. An uninitialised pointer contains garbage memory garbage and is dangerous.

2. Address-of and dereference operators

C provides two fundamental unary operators for working with pointers:

  • Address-of operator (&): Yields the memory address of its operand.
  • Dereference (indirection) operator (*): Accesses or modifies the value stored at the address contained in the pointer.
addrof_deref.c
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;   /* p stores the address of x */

    printf("Value of x:       %d\n", x);
    printf("Address of x (&x): %p\n", (void *)&x);
    printf("Value of p:       %p\n", (void *)p);
    printf("Dereference (*p): %d\n", *p);

    /* Modifying x through p */
    *p = 99;
    printf("New value of x:   %d\n", x); /* prints 99 */

    return 0;
}

Memory representation

Conceptually, you can visualise memory as an array of numbered byte cells:

VariableAddressStored ValueExplanation
x0x7ffee442 (or 99)An integer variable occupying 4 bytes
p0x7ffee80x7ffee4A pointer variable holding the address of x

When you evaluate *p, the CPU reads the address stored inside p (0x7ffee4) and navigates to that cell to read or write the integer value.

3. Pointer types and sizes

Why do pointers have types like int *, char *, and double * if all memory addresses are just numbers? There are two primary reasons:

  1. Dereference width: When you write *p, the compiler needs to know how many bytes to read/write (e.g. 1 byte for char, 4 bytes for int, 8 bytes for double) and how to interpret those bits.
  2. Pointer arithmetic scaling: Adding 1 to a pointer must advance it by the size of the pointed-to object.

However, all pointer types on a given platform have the exact same size, because an address is always the same width regardless of what resides at that location.

ptr_sizes.c
#include <stdio.h>

int main(void) {
    printf("sizeof(char *)   = %zu bytes\n", sizeof(char *));
    printf("sizeof(int *)    = %zu bytes\n", sizeof(int *));
    printf("sizeof(double *) = %zu bytes\n", sizeof(double *));
    printf("sizeof(void *)   = %zu bytes\n", sizeof(void *));
    return 0;
}

4. Pointer arithmetic

C allows arithmetic on pointers: addition, subtraction, increment, decrement, and difference. Crucially, pointer arithmetic is scaled by the size of the pointed-to type:

  • p + 1 advances the address by 1 * sizeof(*p) bytes.
  • p + n advances the address by n * sizeof(*p) bytes.
ptr_arith.c
#include <stdio.h>
#include <stddef.h>

int main(void) {
    int arr[5] = {10, 20, 30, 40, 50};
    int *p = arr; /* points to arr[0] */

    printf("p     = %p, *p     = %d\n", (void *)p, *p);
    printf("p + 1 = %p, *(p+1) = %d\n", (void *)(p + 1), *(p + 1));

    /* Iterating an array with a pointer */
    int *end = arr + 5; /* pointer to one-past-the-end */
    for (int *curr = arr; curr < end; ++curr) {
        printf("%d ", *curr);
    }
    printf("\n");

    /* Pointer difference */
    int *p0 = &arr[1];
    int *p1 = &arr[4];
    ptrdiff_t diff = p1 - p0; /* yields 3 (number of elements, not bytes) */
    printf("p1 - p0 = %td elements\n", diff);

    return 0;
}
💡
Subtracting two pointers to elements of the same array yields a signed integer of type ptrdiff_t (from <stddef.h>). Print it using the %td format specifier.

5. Pointers and arrays

In C, array names and pointers are intimately linked through the concept of array decay: in most expressions, the name of an array decays into a pointer to its first element (&arr[0]).

The equivalence rule

By definition in the C standard, array indexing a[i] is strictly syntactic sugar for *(a + i):

  • a[i] is identical to *(a + i)
  • Because addition is commutative, *(a + i) is identical to *(i + a), which means even i[a] is valid C!
decay.c
int arr[3] = {100, 200, 300};
int *p = arr; /* decays to &arr[0] */

printf("%d\n", arr[1]);   /* 200 */
printf("%d\n", *(arr + 1)); /* 200 */
printf("%d\n", p[1]);     /* 200 */
printf("%d\n", *(p + 1));   /* 200 */

Key differences: Array vs Pointer

PropertyArray (int a[5])Pointer (int *p)
Memory allocationAllocates space for 5 contiguous ints (20 bytes)Allocates space only for the pointer address (8 bytes)
sizeof operatorsizeof(a) gives total array size (20)sizeof(p) gives pointer size (8)
ReassignmentCannot be reassigned (not a modifiable lvalue)Can be reassigned to point elsewhere (p = q)

Pointer to first element vs Pointer to entire array

  • int *p = arr; — pointer to an int (first element). p + 1 steps by sizeof(int).
  • int (*parr)[5] = &arr; — pointer to an array of 5 ints. parr + 1 steps by 5 * sizeof(int) (the whole array).

6. const pointers

The const qualifier can be applied to pointers in four distinct combinations depending on whether the qualifier is placed before or after the asterisk (*). Use the "read right-to-left" rule to understand them:

DeclarationMeaningCan Change Pointer?Can Change Value?
int *pPointer to non-const intYes (p = &b)Yes (*p = 10)
const int *p (or int const *p)Pointer to const int (data is read-only)Yes (p = &b)No (*p = 10 is compile error)
int * const pConst pointer to non-const int (pointer is fixed)No (p = &b is compile error)Yes (*p = 10)
const int * const pConst pointer to const int (both fixed)No (compile error)No (compile error)
const_ptr.c
int a = 10, b = 20;

/* 1. Pointer to const int: protects the target value */
const int *p1 = &a;
p1 = &b;        /* OK: can redirect pointer */
/* *p1 = 30; */ /* ERROR: read-only location */

/* 2. Const pointer to int: protects the address */
int * const p2 = &a;
*p2 = 30;       /* OK: can modify value */
/* p2 = &b; */  /* ERROR: assignment of read-only variable */

/* 3. Const pointer to const int: completely immutable */
const int * const p3 = &a;
/* *p3 = 40; */ /* ERROR */
/* p3 = &b;  */ /* ERROR */
💡
Whenever you write a function that only reads from a buffer without modifying it (e.g. strlen(const char *s)), always declare the parameter as const Type *. This documents intent and allows string literals and const variables to be safely passed.

7. Double pointers (Pointers to pointers)

A pointer variable itself lives at a memory address. A pointer that stores the address of another pointer is called a pointer to a pointer, or double pointer (Type **).

double_ptr.c
int val = 58;
int  *p  = &val;  /* p holds address of val */
int **pp = &p;    /* pp holds address of p */

printf("val   = %d\n", val);   /* 58 */
printf("*p    = %d\n", *p);    /* 58 */
printf("**pp  = %d\n", **pp);  /* 58 */

Why are double pointers needed?

  1. Modifying a caller's pointer in a function: In C, all arguments are passed by value. To modify an int in the caller, you pass an int *. Therefore, to modify an int * in the caller (e.g., dynamically allocating or reallocating memory), you must pass an int **.
  2. Arrays of pointers / Strings: Command-line arguments in main(int argc, char **argv) represent an array of strings (where each string is a char *).

8. Generic pointers: void *

A void * is a generic pointer capable of holding the address of any data type without an explicit cast. In standard C, any data pointer converts implicitly to and from void *.

However, because void has no known size:

  • You cannot dereference a void * directly without casting it to a concrete pointer type (e.g. *(int *)ptr).
  • Standard C forbids pointer arithmetic on void * (because sizeof(void) is undefined).
void_ptr.c
#include <stdio.h>

void print_bytes(const void *data, size_t size) {
    /* Cast void * to const unsigned char * to inspect byte by byte */
    const unsigned char *bytes = (const unsigned char *)data;
    for (size_t i = 0; i < size; ++i) {
        printf("%02X ", bytes[i]);
    }
    printf("\n");
}

int main(void) {
    int num = 0x12345678;
    double pi = 3.14159;

    print_bytes(&num, sizeof(num));
    print_bytes(&pi, sizeof(pi));
    return 0;
}

9. Function pointers

In C, code instructions also live in memory. The entry point of a compiled function has an address, which can be stored in a function pointer. This enables callbacks, dynamic dispatch tables, and plugin architectures.

Syntax

The parentheses around (*fn_name) are mandatory because int *f(int) declares a function returning an int *, whereas int (*f)(int) declares a pointer to a function returning an int.

fn_pointer.c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int mul(int a, int b) { return a * b; }

/* Using typedef makes function pointer types clean and readable */
typedef int (*bin_op)(int, int);

void compute_and_print(bin_op op, int x, int y) {
    printf("Result: %d\n", op(x, y));
}

int main(void) {
    compute_and_print(add, 10, 5); /* prints 15 */
    compute_and_print(mul, 10, 5); /* prints 50 */
    return 0;
}

10. Common pointer bugs and how to avoid them

Pointers are C's most powerful feature, but incorrect usage leads to bugs, memory corruption, and security vulnerabilities.

1. Uninitialised pointer

Declaring a pointer without initialising it creates a wild pointer pointing to random memory.

🛑
int *p; *p = 10; — Writing to an uninitialised pointer causes undefined behaviour (often an immediate crash / segmentation fault). Always initialise with NULL or a valid address.

2. NULL pointer dereference

Attempting to read or write through a NULL pointer is undefined behaviour and will crash your application on modern OSes.

⚠️
Always verify pointer validity with if (p != NULL) before dereferencing, especially when receiving pointers as function arguments or from memory allocation functions.

3. Dangling pointer

A dangling pointer points to memory that is no longer valid, such as a local stack variable from a returned function or heap memory that has been free()'d.

dangling_bug.c
int *get_bad_pointer(void) {
    int local_var = 42;
    return &local_var; /* BUG: local_var is destroyed when function returns! */
}

4. Pointer aliasing and strict aliasing

Two pointers alias when they point to the same memory location. The C strict aliasing rule states that two pointers of different types (other than char * or void *) cannot point to the same location. Violating this rule by casting arbitrary pointers can lead to aggressive and unexpected compiler optimisation bugs.

Summary

  • A pointer stores the memory address of an object. Use & to get an address and * to dereference.
  • On a given system, all pointer types have the same size (e.g. 8 bytes on 64-bit systems).
  • Pointer arithmetic is scaled by sizeof(*p) bytes.
  • Array names decay to pointers to their first element in expressions: a[i] is *(a + i).
  • const int *p protects the data; int * const p protects the pointer address.
  • Double pointers (Type **) allow functions to modify caller pointer variables and represent pointer arrays.
  • void * is a generic pointer that can hold any address, but must be cast before dereferencing.
  • Always guard against uninitialised pointers, null dereferences, and dangling pointers.
