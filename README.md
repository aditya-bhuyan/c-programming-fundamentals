# C Programming Fundamentals

A free, open-source learning platform for the C programming language — featuring structured chapter content, code examples, quizzes, coding exercises, and solutions.

🌐 **Live site:** https://c-programming-fundamentals.netlify.app

## What's Inside

Each chapter follows a consistent five-part structure:

| Section | Description |
|---|---|
| 📖 Learning Material | Concept explanation with diagrams and notes |
| 💻 Code Examples | Runnable, annotated C programs |
| 🧠 Quiz | Multiple-choice questions to test understanding |
| 🏋️ Coding Exercises | Hands-on problems for the learner to solve |
| ✅ Solutions | Reference solutions with explanations |

## Chapters

1. **Getting Started** — Environment setup, compiling and running C on Windows, macOS, and Linux
2. **Variables & Data Types**
3. **Operators & Expressions**
4. **Control Flow** — if/else, switch, loops
5. **Functions**
6. **Arrays & Strings**
7. **Pointers**
8. **Structures & Unions**
9. **File I/O**
10. **Dynamic Memory Management**
